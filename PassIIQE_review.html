💡 溫馨提示：以下內容深入解釋系統後台運行的 **AI 演算法、項目反應理論 (IRT) 數學模型、知識追蹤與神經突觸記憶原理**。純屬教育科技原理探究，若你只想輕鬆快速通關 IIQE 考試，完全可以略過此部分不看！

1. 項目反應理論 (Item Response Theory, IRT) 與自適應難度 (CAT)

點解考生會感覺學習效率極高？因為題目永遠落在你的「最近發展區 (ZPD)」！

傳統刷題最大弊病是「亂做一通」：題目太易浪費時間，題目太難令人沮喪。PassIIQE 採用三參數 Logistic (3PL) IRT 演算法模型：
P(θ) = c + (1 - c) / [1 + e^(-a * (θ - b))]
• 能力值 θ (Theta)：AI 根據你即時作答動態推算你的當前實力。
• 難度 b 與區分度 a：AI 自動挑選最適合你當前水平、略高於你舒適區的試題。答題流暢不卡頓，瞬間進入心理學上的「心流狀態 (Flow State)」，學習效率自然飆升！

2. 貝葉斯知識追蹤模型 (Bayesian Knowledge Tracing, BKT)

精準鎖定未掌握知識點，杜絕無效重複練習！

系統將 IIQE 拆解為 78 個核心法規知識元（Knowledge Components, KC）。每次作答，AI 透過隱馬爾可夫鏈即時更新掌握機率：
P(L_t | Correct) = [P(L_t-1) * (1 - Slip)] / [P(L_t-1) * (1 - Slip) + (1 - P(L_t-1)) * Guess]
只要系統發現你在「不可爭辯條款」或「寬限期扣費」的掌握度低於 0.8，演算法會自動在練習中提高該知識點的變形題權重，直到真正學識為止。

3. 改進型 FSRS / 艾賓浩斯間隔排程 (Spaced Repetition Engine)

在記憶衰減的「黃金臨界點」精準重現，產生合意困難 (Desirable Difficulties)

人腦在記住新知識後，24 小時內會遺忘近 70%。易考通結合答題耗時、猶豫時長與用戶點擊「我明白 / 仍然唔明」，計算記憶穩定度因子 $S$。系統精確計算出該題目在 第 1 天、第 3 天、第 7 天 的最佳召回時間，趁記憶即將消退之際強迫大腦主動提取，突觸永久固化。
